# Sources, attribution and asset terms

This repository is an academic inference replication. Different inputs and upstream components retain their own terms; publication of this project does not grant new rights to third-party material.

- **TinyCD paper:** Codegoni, Lombardi and Ferrari, *TinyCD: A (Not So) Deep Learning Model for Change Detection*, Neural Computing and Applications 35 (2023), [DOI](https://doi.org/10.1007/s00521-022-08122-3). The project implementation is in `cdlib/models/tinycd.py`. Released weights are downloaded directly from the [authors' repository](https://github.com/AndreaCodegoni/Tiny_model_4_CD); their SHA-256 is checked. The publication PDF is not redistributed.
- **BIT:** Chen, Qi and Shi, *Remote Sensing Image Change Detection with Transformers*. [Official repository](https://github.com/justchenhao/BIT_CD), commit `adcd7aea6f234586ffffdd4e9959404f96271711`. No upstream licence file is present. Therefore source files and weights are not republished here. `scripts/bootstrap_bit.py` downloads three pinned source files, verifies their original hashes, and applies the documented import/initialization patches locally. Setup downloads the authors' checkpoint from their linked Google Drive location.
- **ChangeFormer:** Bandara and Patel, *A Transformer-Based Siamese Network for Change Detection*. [Official repository](https://github.com/wgcban/ChangeFormer), commit `afd1b7ed640aa265a2c730de958416ae7356a2f9`. Vendored model files retain [the MIT licence](cdlib/models/vendor/changeformer/LICENSE). The released checkpoint is downloaded from the authors' GitHub release, not committed here.
- **LEVIR-CD:** Chen and Shi, *A Spatial-Temporal Attention-Based Method and a New Dataset for Remote Sensing Image Change Detection*, Remote Sensing 12(10), 1662 (2020), [DOI](https://doi.org/10.3390/rs12101662). [Dataset page and usage terms](https://justchenhao.github.io/LEVIR/). Images and annotations are for academic use only; commercial use is prohibited, and the underlying Google Earth imagery terms apply. The six fixed examples in `assets/demo/` are an attributed academic demonstration subset. The full LEVIR-CD256 archive is fetched from the source linked by ChangeFormer and hash-verified, not hosted in this repository.
- **Landsat Powai pair:** Credit: U.S. Geological Survey. Landsat 8 Collection 2 Level-2 scenes `LC08_L2SP_148047_20150210_20200909_02_T1` and `LC08_L2SP_148047_20250205_20250208_02_T1`. [Dataset DOI](https://doi.org/10.5066/P9OGBGM6), [USGS credits policy](https://www.usgs.gov/information-policies-and-instructions/copyrights-and-credits). The small processed RGB/quality crops and their provenance are included; original full-scene downloads are not. The derived model predictions are exploratory and lack reference change labels.
- **Bootstrap Python:** [Astral python-build-standalone](https://github.com/astral-sh/python-build-standalone), release `20261026`, CPython 3.12.16. Setup checks the platform archive SHA-256 before extraction. The distribution retains its included Python and bundled-library licence notices; the runtime is downloaded locally rather than committed.
- **Sentinel-2 campus previews:** Contains modified Copernicus Sentinel data (2017 and 2025), accessed via Element 84 Earth Search / AWS Open Data. Native 10 m true-colour crops and source records are included in `assets/powai/sentinel2_preview/` for inspection, not model evaluation. See [Copernicus Sentinel-2 data access](https://dataspace.copernicus.eu/data-collections/copernicus-sentinel-missions/sentinel-2) and the folder's provenance record.

Historical benchmarks retain their original environment and measurement dates. Private course documents, archived training runs, personal agent configuration, downloaded runtimes and local credentials are not part of the public snapshot.
